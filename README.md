# claude-desktop-hotkeys

StrokesPlus.net 단축키로 ChatGPT Windows 앱과 Claude Desktop을 조작하고, 어느 앱에서나 선택한 영어를 한국어로 번역합니다.

## 단축키

| 단축키 | 기능 | 앱 | 마우스 |
|---|---|---|---|
| `Ctrl+Alt+↑/↓` | 추론 강도 한 단계 위/아래 | ChatGPT, Claude | Claude 안 씀 |
| `Ctrl+Alt+/` | 입력란 포커스 | ChatGPT, Claude | 클릭 1번 |
| `Ctrl+Alt+S` | 보관된 세션 열기 | Claude Code | 안 씀 |
| `Ctrl+Alt+D` | md 미리보기 ↔ 소스, 파일 창 열기/닫기 | Claude Code | 안 씀 |
| `Ctrl+Alt+B` | 백그라운드 작업 창 열기/닫기 | Claude Code | 안 씀 |
| `Ctrl+Alt+T` | 선택한 텍스트를 한국어로 번역 | 모든 앱 | 안 씀 |
| ``Alt+` `` | `` ` `` 키를 마우스 왼쪽 클릭으로 켜기/끄기 | 모든 앱 | 클릭 |

- 대상이 아닌 앱에서는 원래 키 조합을 그대로 그 앱에 전달합니다. 번역 `T`는 모든 앱이 대상입니다.
- ChatGPT의 추론 강도는 마우스 없는 방식을 먼저 시도하고, 안 되면 마우스를 씁니다([동작](#동작) 참고).
- `/`는 숫자 키패드가 아니라 문자 키의 `/`입니다.
- `Ctrl+Alt+A`는 Claude 자체 단축키(세션 보관)라 쓰지 않습니다.
- `Ctrl+Alt+S`는 사이드바 `그룹화 및 정렬` 메뉴의 `모두 보기`로 세션 화면을 열고 `보관됨` 탭을 고릅니다. 세션 화면이 이미 열려 있으면 탭만 고릅니다. 사이드바에는 활성 세션이 항상 보입니다.
- `Ctrl+Alt+D`는 파일 창에 `.md` 파일이 열려 있으면 미리보기와 소스를 바꿉니다. `.md` 보기가 없으면 파일 창을 열고, 파일 창이 `.md` 없이 열려 있으면 닫습니다.
- 번역은 `Ctrl+Shift+T`가 브라우저의 "닫은 탭 다시 열기"와 겹쳐 `Ctrl+Alt+T`를 씁니다. 자세한 내용은 [선택 영역 번역](#선택-영역-번역)을 참고하세요.
- ``Alt+` ``를 누르면 `` ` `` 키가 마우스 왼쪽 버튼이 되고, 다시 누르면 원래대로 돌아옵니다. 켜고 끌 때마다 화면 오른쪽 아래에 `Backtick ON` / `Backtick OFF` 알림이 잠깐 뜹니다. 켜져 있는 동안 `` ` ``를 누르면 지금 커서 위치에서 버튼이 눌리고, 떼면 버튼도 떼어지므로 누른 채 움직이면 드래그가 됩니다. ``Shift+` ``(`~`) 같은 다른 조합은 그대로 입력됩니다. 꺼져 있을 때는 아무것도 실행되지 않습니다. 관리자 권한으로 실행된 창에는 클릭이 전달되지 않을 수 있습니다.
- `Ctrl+Alt+B`는 백그라운드 작업 창(`/tasks`로 보는 작업 목록)을 엽니다. 닫혀 있으면 오른쪽 위 `보기 옵션` 메뉴의 `백그라운드 작업`을 켜고, 열려 있으면 창의 `닫기` 버튼을 누릅니다. 입력란에 글을 치지 않으므로 쓰던 글이 있어도 됩니다.

### 추론 단계

| 앱 · 모델 | 단계 |
|---|---|
| ChatGPT · GPT-6.1 Sol | Light → Medium → High → Extra High → Ultra |
| Claude Code 탭 · Opus 5.5 | 낮음 → 중간 → 높음 → 엑스트라 → 최대 → Ultracode |
| Claude Chat 탭 · Opus 5.5 | 낮음 → 중간 → 높음 → 엑스트라 → 최대 |

- ChatGPT는 ChatGPT 모드와 Codex 모드 모두 지원합니다. Claude의 `중간`은 `보통`으로 표시돼도 인식합니다.
- 양 끝에서는 현재 단계를 유지합니다.
- 다른 모델이 선택돼 있으면 바꾸지 않고 중단합니다.

## 선택 영역 번역

브라우저, PDF 뷰어, 메모장, 터미널 등에서 영어를 드래그한 뒤 `Ctrl+Alt+T`를 누르면 마우스 커서 옆 팝업에 한국어 번역이 나옵니다.

- 번역 중에는 `번역 중…`과 경과 시간을 표시합니다. 보통 몇 초 걸립니다.
- `복사` 버튼이나 `Ctrl+C`(본문을 선택하지 않았을 때)로 번역문 전체를 복사합니다. 본문 일부를 드래그해 복사할 수도 있습니다.
- `Esc`나 `닫기`로 닫으면 원래 창으로 돌아갑니다. 다른 곳을 클릭해도 팝업은 남아 있어 원문과 나란히 읽을 수 있고, 다시 `Ctrl+Alt+T`를 누르면 새 팝업으로 바뀝니다.
- 선택 영역은 `Ctrl+C`로 복사해 읽고, 원래 클립보드 내용을 바로 되돌립니다. 터미널(Windows Terminal, 콘솔, mintty 등)에서는 선택이 없을 때 `Ctrl+C`가 실행 중인 프로그램을 멈추므로 `Ctrl+Insert`로 복사합니다. 되돌릴 수 없는 특수 형식(일부 앱 전용 개체)은 복원되지 않을 수 있습니다.
- 번역은 Claude Code CLI를 비대화형으로 실행해 Haiku 모델로 합니다: `claude -p --model haiku --tools "" --no-session-persistence --strict-mcp-config`. 선택한 텍스트는 명령줄이 아니라 표준 입력(UTF-8)으로 넘기고, 도구·MCP 서버·세션 기록 없이 임시 폴더에서 실행합니다. 지시문은 `다음 텍스트를 자연스러운 한국어로 번역해. 설명 없이 번역문만 출력해:`입니다.
- 한 번에 8,000자까지 번역하고, 90초 안에 응답이 없으면 멈춥니다.

### Claude Code CLI 준비

`claude`를 PATH, `%USERPROFILE%\.local\bin`, `%APPDATA%\npm` 순서로 찾고, 없으면 Claude 데스크톱 앱에 들어 있는 CLI(`%APPDATA%\Claude\claude-code\<버전>\…\claude.exe`, 또는 앱 패키지 폴더 `%LOCALAPPDATA%\Packages\Claude_…\LocalCache\Roaming\Claude\claude-code\<버전>\…\claude.exe`) 중 가장 최근 것을 씁니다. 앱 밖에서는 앞의 경로가 앱 업데이트 뒤 비어 있을 수 있어 패키지 폴더도 찾습니다. 어느 것이든 **로그인된 상태**여야 합니다. 데스크톱 앱 안의 CLI는 앱 밖에서 실행하면 로그인되어 있지 않을 수 있습니다.

CLI의 `/login` 로그인은 다른 프로그램이 먼저 갱신하면 풀릴 수 있습니다. 로그인이 자꾸 풀리면 1년짜리 토큰을 쓰세요. 구독 사용량에서 차감되는 것은 같고, 추가 요금은 없습니다.

1. 터미널에서 `claude setup-token`을 실행합니다. 브라우저에서 승인하면 토큰이 출력됩니다.
2. 출력된 토큰을 `%APPDATA%\claude-desktop-hotkeys\claude-token.txt`에 저장합니다. 이 파일이 있으면 번역할 때 그 토큰을 `CLAUDE_CODE_OAUTH_TOKEN`으로 넘기고, CLI 자체의 로그인은 쓰지 않습니다.

토큰은 1년 동안 계정을 쓸 수 있는 열쇠이므로 다른 곳에 올리지 마세요. 만료되거나 취소되면 팝업이 같은 방법으로 다시 발급하라고 안내합니다.

CLI가 없으면 PowerShell에서 설치한 뒤 `claude`를 한 번 실행해 `/login` 합니다.

```powershell
irm https://claude.ai/install.ps1 | iex
```

설정이 됐는지는 팝업 없이 다음 명령으로 확인합니다. 예문 한 줄을 번역해 결과를 `last-result-translate.txt`에 씁니다.

```powershell
.\ReasoningSwitch.exe --translate-check
Get-Content .\last-result-translate.txt
```

CLI를 찾지 못하거나, 로그인이 안 됐거나 만료됐거나, 실패하면 팝업에 원인과 할 일을 표시합니다.

## 설치

Windows, x64 .NET Framework 및 StrokesPlus.net이 필요합니다. StrokesPlus.net 0.5.7.8의 기본 설치 경로(`C:\Program Files\StrokesPlus.net`)에서 확인했습니다.

1. 저장소를 내려받습니다. 권장 폴더는 Windows 문서 폴더의 `_ETC\claude-desktop-hotkeys`입니다.
2. 실행 중인 StrokesPlus.net을 트레이 메뉴의 **Exit**로 종료합니다.
3. 내려받은 폴더에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

설치 프로그램은 StrokesPlus 설정을 백업하고 `AI Reasoning` 분류에 여덟 단축키를 등록한 뒤 StrokesPlus를 실행합니다. 다른 설정과 단축키는 보존합니다. 실행 경로는 설치한 폴더에 맞춰 생성하므로 다른 폴더에 설치해도 됩니다. 폴더를 이동하거나 이름을 바꾸면 새 위치에서 설치를 다시 실행하세요.

설정 변경 없이 확인하거나 이 여덟 단축키만 제거하려면 다음 명령을 사용합니다.

```powershell
.\Install.ps1 -DryRun
.\Install.ps1 -Undo
```

`Up.js`, `Down.js`, `Input.js`, `Status.js`, `Markdown.js`, `Tasks.js`, `Translate.js`는 수동 등록용 스크립트입니다. 기본 경로는 Windows 문서 폴더의 `_ETC\claude-desktop-hotkeys`이며, 다른 위치에서는 `reasoningHelper`를 변경하세요. `Hotkeys.json`은 설치 프로그램이 사용하는 템플릿입니다.

## 동작

### 한눈에 보기

"접근성"은 Windows UI Automation입니다. 화면의 버튼과 메뉴를 이름으로 찾아 마우스 없이 누릅니다.

| 대상 | 방식 | 확인 | 실패 시 |
|---|---|---|---|
| Claude 노력 (Code, Chat) | 모델 메뉴 → `노력` 줄 + `→` → 단계 선택 | 메뉴 표시, 모델 버튼 이름 | 마우스 클릭 |
| ChatGPT 노력 \* | 버튼 열기 → 슬라이더 값 지정 → 닫기 | 슬라이더 값, 버튼 이름 | 이미지 + 마우스 |
| 보관된 세션 `S` | `그룹화 및 정렬` → `모두 보기` → `보관됨` 탭 | 탭 선택 상태 | 오류 알림 |
| md 보기 `D` | 보기 전환 버튼, 없으면 `파일` 버튼 | 버튼 이름, 파일 창 열림/닫힘 | 오류 알림 |
| 입력란 `/` | 입력란 클릭 1번 | 입력란 포커스 | 오류 알림 |
| 작업 창 `B` | 열 때 `보기 옵션` → `백그라운드 작업` 체크, 닫을 때 창의 `닫기` 버튼 | 작업 창 나타남/사라짐 | 오류 알림 |

- 각 단계는 접근성 명령이고, 코드 서식으로 쓴 `→`만 실제 키 입력(오른쪽 방향키)입니다.
- "오류 알림"은 아무것도 바꾸지 않고 알림만 띄운다는 뜻입니다.
- Claude 앱 2.42304.0(2026-10-16 확인)부터 Claude Code 탭의 별도 노력 버튼(슬라이더)이 없어지고, Chat 탭처럼 모델 버튼(`모델: Opus 5.5 높음`)의 메뉴로 옮겨졌습니다. Code 탭 하위 메뉴에만 `Ultracode`가 있습니다. 예전 노력 버튼이 보이는 버전에서는 슬라이더 방식을 그대로 씁니다.
- md 보기 버튼은 바뀔 보기를 이름으로 가집니다(`소스 보기` ↔ `미리보기`).
- \* ChatGPT 경로는 실제 창에서 아직 확인하지 않았습니다. 어느 방식으로 동작했는지는 `last-action-chatgpt.txt`의 결과 줄에 `(slider verified)` 또는 `(image verified)`로 남습니다.

### 공통 규칙

- **키 해제 대기**: 시작할 때와 `→` 키를 보내기 전에 Ctrl·Alt·Shift·Win·단축키가 모두 놓였는지 확인합니다. `Ctrl+Alt+→`는 Claude의 "다음 사이드바 탭"이기 때문입니다. 3초 안에 놓이지 않으면 중단합니다. 접근성 명령만 쓰는 `S`, `D`, `B`는 키를 누른 채여도 상관없어 기다리지 않고 바로 시작합니다.
- **키 입력**: 노력 하위 메뉴를 여는 `→` 한 번뿐입니다. 하위 메뉴만 접근성 명령에 반응하지 않습니다. Esc와 SendKeys는 쓰지 않습니다.
- **포커스 복귀**: 마우스를 쓰지 않는 흐름은 끝난 뒤 원래 있던 바로 그 입력란으로 포커스를 되돌립니다(md 보기 `D`, 작업 창 `B` 포함, 세션 화면으로 넘어가는 `S`는 제외). 파일 창의 `파일 필터링` 칸도 입력란이라, 다른 입력란이 아니라 원래 입력란인지 확인합니다. 팝업이 닫히고 약 0.1초 뒤 앱이 포커스를 버튼으로 가져가므로, 입력란에 자리 잡을 때까지 최대 0.6초 다시 시도합니다.
- **한글 입력기 재연결**: 접근성 명령으로 포커스를 옮기거나 버튼·메뉴를 누르면 Windows 포커스가 Claude 창의 `Chrome_RenderWidgetHostHWND` 자식 창으로 넘어가면서 한글 입력기 연결이 끊겨, 첫 글자가 화면 왼쪽 위에 조합되고 다음 글자를 쳐야 들어가는 상태가 됩니다(창을 다시 활성화하면 풀림). 그래서 이런 명령을 쓴 실행(노력, `S`, `D`, `B`)이 끝나면 짧게 뜨는 두 번째 프로세스가 보이지 않는 창으로 활성화를 잠깐 넘겼다가 약 0.1초 만에 Claude로 돌려줍니다. 그 사이 다른 창으로 옮겨 가 있으면 아무것도 하지 않습니다.
- **실행 중 입력 보류**: 입력란 `/`를 뺀 실행 중(약 0.5–1초)에 친 키는 입력란에 닿지 않거나 끊긴 입력기로 들어가므로, 실행이 시작될 때부터 입력기 재연결이 끝날 때까지 붙잡아 두었다가 같은 순서로 다시 칩니다. 단축키의 Ctrl·Alt처럼 시작 전부터 눌려 있던 키를 놓는 입력은 붙잡지 않습니다. 최대 3초만 붙잡고, 메모리에만 두며 기록하지 않습니다.
- **메뉴 포커스**: 막 열린 메뉴는 잠시 뒤 포커스를 가져가므로, 줄에 포커스가 잡힐 때까지 최대 0.5초 반복합니다. 그래도 하위 메뉴가 안 열리면 메뉴를 한 번 다시 엽니다.
- **대화 내용과 구분**: 메뉴 항목은 메뉴 안에서만 이름으로 찾습니다.
- **창 확인**: 활성 창이 바뀌면 최대 0.3초 기다리고, 그동안은 누르지 않습니다. 돌아오지 않으면 앞에 있던 창의 프로세스 이름과 창 클래스를 기록하고 중단합니다.
- **첫 조회**: Claude는 접근성 정보를 요청받은 뒤에 만들기 때문에 앱을 켠 직후에는 창 테두리 버튼만 보일 수 있습니다. 모델 버튼이 나타날 때까지 최대 1.5초 다시 조회하고, 다른 모델의 버튼이 보이면 바로 중단합니다.

### 이미지 검색 + 마우스 방식

ChatGPT와, 접근성이 안 될 때의 예비 경로입니다.

1. 팝업을 실제 마우스 클릭으로 엽니다. 이미 열려 있으면 그대로 씁니다.
2. 팝업의 고정 안내 문구를 StrokesPlus 이미지 검색으로 찾고, 흰 손잡이로 현재 단계를 읽습니다.
3. 목표 칸을 클릭하고 바뀐 손잡이로 확인합니다.
4. 입력란을 클릭해 팝업을 닫습니다.
   - GPT: 팝업 닫힘과 입력란 포커스를 함께 확인하고, 안 되면 창과 위치를 다시 검사한 뒤 한 번 재시도합니다.
   - Claude: 팝업이 보이면 포커스 정보와 상관없이 입력란을 클릭합니다.

- GPT 팝업은 약간 비쳐서 뒤의 대화 글에 따라 픽셀이 몇 단계 어두워집니다. 그래서 채널당 16단계 차이까지 일치로 봅니다(측정한 최대 차이는 5단계).
- 참조 이미지는 한국어 UI와 밝은 테마에서 캡처했습니다. 화면 배율·테마·앱 UI가 달라 일치하지 않으면 전환을 중단하며, 별도 조정이 필요합니다.

## 빌드와 검사

```powershell
.\Build.ps1
.\ReasoningSwitch.exe --selftest
```

빌드는 여섯 C# 소스를 x64 실행 파일로 컴파일하고 자체 검사에 통과한 파일만 적용합니다. 이미지 검사에는 설치된 StrokesPlus.net이 필요합니다. `--selftest`는 첨부 이미지와 생성한 검사 캔버스만 사용하며 앱 화면을 캡처하거나 입력하지 않습니다.

사용 중인 실행 파일을 건드리지 않고 빌드만 확인하려면 다른 폴더를 지정합니다. 참조 이미지도 그 폴더로 함께 복사합니다.

```powershell
.\Build.ps1 -OutputDirectory C:\Temp\reasoning-build
```

빌드 이름은 `ReasoningSwitch.cs`의 `BuildName` 한 곳에서 정의하고, `Build.ps1`은 그 값을 읽어 결과에 표시합니다.

현재 버전은 **38-login-expired**입니다. 자체 검사 항목:

- 단계 이름, 양방향 이동과 경계, 노력 하위 메뉴 항목 이름과 Code 탭 여섯 단계·Chat 탭 다섯 단계의 경계, ChatGPT 모드 이름
- 활성 창이 잠깐 바뀐 경우의 대기와 돌아오지 않는 경우의 중단
- 모델 버튼과 창 테두리 버튼의 구분, 제목에 모델 이름이 들어간 사이드바 세션의 거부
- 실제 참조 이미지의 손잡이, 뒤 내용 때문에 어두워진 GPT 팝업의 인식
- 팝업이 남은 상태의 포커스 정보, 첫 클릭이 무시된 경우의 재시도, 입력란 클릭 위치
- 세션 화면 `보관됨` 탭과 Markdown 보기 버튼의 이름
- 번역: 팝업 위치(화면 가장자리에서 반대쪽으로), 로그인 안 됨·로그인 만료·기타 실패 메시지, `claude.exe`와 `claude.cmd` 실행 명령줄과 UTF-8 출력, 줄바꿈 정리와 터미널 판별
- 최적화: 일부 글자만 일치하는 가짜 후보의 거부와 실제 팝업 복구, 창 밖으로 벗어나는 검색 영역, 잘라낸 이미지의 여섯 단계, 다른 모니터 좌표 변환

## 성능

이미지 검색 방식에 해당합니다.

- Claude는 처음 팝업을 찾을 때 버튼 주변부터 검색하고, 찾은 뒤에는 최대 320×180 영역만 캡처합니다. 작은 범위에서 못 찾으면 전체 창을 다시 검색하므로 팝업 위치가 바뀌어도 복구합니다. 참조 이미지는 실행 중 한 번만 읽습니다.
- 큰 이미지에서는 공백으로 시작하는 검색 키의 글자 부분을 먼저 찾습니다. 작은 키가 일치해도 원래 안내 문구의 모든 픽셀을 검증한 뒤 좌표를 반환하고, 일부 글자만 같은 후보가 먼저 나오면 원래 검색으로 실제 팝업을 찾습니다.
- Claude의 모델·추론 버튼은 한 번의 접근성 조회에서 찾습니다. 입력란에 이미 포커스가 있으면 그 입력란의 메타데이터만 읽고 전체 검색을 생략합니다.
- 2026-10-08의 저장된 이미지와 흰색 합성 캔버스 시험에서 Claude의 2560×1410 검색은 약 634–850ms/회에서 약 30–70ms/회로 줄었습니다. 화면 캡처·앱 반응·접근성 조회를 뺀 검색 함수 측정이라 실제 전환 시간의 개선율은 아닙니다.

접근성 방식의 한 번 실행 시간은 2026-10-14 측정에서 Code 탭 노력 약 0.5초, Chat 탭 노력 약 0.8초였습니다(이미지 방식은 약 0.95초).

## 진단 파일

- `last-result*.txt`: 최근 실행 결과
- `last-action*.txt`: 최근 실행의 단계·소요 시간·포커스 결과, 접근성 조회·이미지 검색·캡처별 시간
- `last-diagnostic*.txt`: 오류 발생 시 모델·추론 컨트롤 정보. 대화 내용이 목록 항목으로 노출되는 화면이 있어 목록 항목은 기록하지 않습니다.
- `chat-input-*.txt`: 같은 창에서 재사용하는 창·프로세스 번호와 입력란 위치
- `last-result-translate.txt`: 최근 번역의 결과·소요 시간·사용한 `claude` 경로. 원문과 번역문은 기록하지 않습니다.
- `selftest-error.txt`: `--selftest`가 예외로 실패했을 때의 오류 내용
- `StrokesPlus.before-*.json`: 설치 전 개인 설정 백업

이름에 `-chatgpt`, `-claude`가 붙은 파일은 앱별 최근 기록입니다.

번역 `T`를 빼면 실행 파일은 네트워크나 클립보드에 접근하지 않으며 대화를 전송하지 않습니다. 번역 `T`는 선택 영역을 읽으려고 클립보드를 잠깐 쓰고, 선택한 텍스트를 Claude Code CLI를 통해 Claude로 보냅니다. 입력란의 본문을 읽거나 로그로 저장하지 않습니다. 화면 캡처는 이미지 검색을 위해 메모리에서만 사용합니다. 개인 설정 백업과 진단·위치 파일은 Git에서 제외됩니다.
